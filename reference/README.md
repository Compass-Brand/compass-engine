# Reference Materials

`reference/` is the retained framework, provenance, audit, and research area for Compass Engine.

Current rule:

- keep workflow/framework references, provenance notes, audits, and research here
- keep shipped implementation in `src/`
- do not treat `reference/` as the active runtime source tree

Rules:

- Do not store legacy or archived implementation dumps here.
- Keep this directory focused on framework context that should not ship.
- If a file is stale or superseded, delete it instead of turning `reference/` into a second implementation tree.
